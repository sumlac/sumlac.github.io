THE FRAMEWORKS / MY POINT OF VIEW

Two factories.
One learning loop.

As agents gain more tools, more context, and more room to act, the important questions sit at the boundaries. Who can access the data? Who can approve the action? What proves that the control still holds?

01 / BLUE TEAM↗

Defense Factory

Make every fix prove itself.

A failure should leave behind a control we can verify again. My focus is the evidence that connects the original finding, the fix, and the next system change.

  • Check authority before an action.
  • Verify blocked and permitted behavior.
  • Carry the evidence into the next test.
READ THE DEFENSE FRAMEWORK →
02 / RED TEAM↗

Offense Factory

Keep challenging the assumptions.

A changed model, tool, permission, or retrieval path should create new hypotheses. My focus is testing the system’s actual behavior and making useful failures reproducible.

  • Turn system changes into new questions.
  • Observe the effect at the boundary.
  • Give defense a case it can replay.

LOOKING AHEAD / OPEN QUESTIONS

What needs to
change next?

The interesting work is in the decisions these factories force us to make. These are the questions shaping my thinking about the next generation of AI security.

01 / AUTHORITY

Who is allowed to act when agents work together?

A task can pass through several agents and tools. The original caller’s permissions should still constrain the final action. I’m interested in where that authority can drift—and how offense and defense should test it.

02 / CHANGE

When does yesterday’s evidence stop being enough?

A model, tool, data path, or permission change can alter the conditions behind a passing test. I want the defense loop to identify which claims need to be checked again.

Follow the defense question ↗
03 / LATENCY

How fast can a secure decision be?

Some checks must happen before an action. Deeper investigation and adversarial replay can happen alongside it. The challenge is deciding where each belongs without postponing the check that protects the data.

04 / LEARNING

Does the next test teach us anything new?

Retained cases help prevent recurrence. New hypotheses help expose the gaps. I want a campaign to make both kinds of progress visible, including the uncertainty that remains.
